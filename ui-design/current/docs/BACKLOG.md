## 功能需求

### [往年今日] 生成回忆卡片图 〔待设计 · 已暂缓〕
把一条（或一天的）回忆渲染成一张精致的**回忆卡片图**，可保存 / 分享。
- **Flutter 落地**：卡片即 widget，`RepaintBoundary.toImage()` → PNG，再走 `share_plus` / 存相册。原型阶段以真实样式 DOM 渲染卡片预览（所见即所得），保存/分享用 toast 模拟即可。
- **待定的设计分叉**（动手前需确认）：
  - 范围：单条回忆卡 / 当日合集卡 / 两者都要。
  - 画幅：竖版 9:16 / 方形 1:1 / 可切换。
  - 卡片元素：配图、正文摘录、日期+第几年前、心情天气、地点、标签、DayZ 字标。
  - 视觉风格数量：1 种（暖纸+衬线最克制）/ 2–3 种可切换（纸感 / 大图压字 / 极简）。
  - 入口：每条卡片右下分享小图标 / 顶部「⋯ 更多」菜单 / 顶部「生成今日回忆」主按钮。
  - 预览后操作：保存到相册、分享、切样式/配色、切画幅。
  - 是否真导出 PNG（原型阶段可仅预览 + toast）。
