# DayZ

> 一款本地优先、注重隐私的日记 App —— 为长久书写而设计的安静系统。

DayZ 把日记放回它该有的样子：像一张温润的纸，安静、克制，把注意力留给你写下的字。浅色是暖白的纸、深色是柔和的炭，中文排版优先，并提供雾紫 / 暖黄 / 雾绿三套可随心切换的主题色与多张适合长读的纸色。

## 设计基调

- **温润 · 安静** —— 大面积留给纸与墨，颜色只在关键处轻点，不喧哗、不抢镜。
- **少即是多** —— 不堆数字、图标、装饰；每样东西都要挣得自己的位置。
- **纸与墨** —— 背景是一张可更换的「纸」，文字是温润的墨，像在真实本子上书写。
- **用最轻的方式表达** —— 状态靠一点颜色、一个小图标说清，而非整块刺眼的红绿。
- **中文优先** —— 正文与日记用更耐读的衬线、行距放宽，先把中文照顾好。

## 主要特性

- **时间线** —— 无限滚动的日记卡片流；多图日记用克制的**九宫格**呈现，超出收起。
- **往年今日** —— 翻出历史上的今天写过什么。
- **富文本编辑** —— 标题、强调、列表、待办、引用、代码、链接、图片（对接 AppFlowy Editor）。
- **侧边抽屉导航 + FAB 速记** —— 导航收进抽屉，写日记集中在一个加号：轻点即写、长按展开拍照 / 语音 / 纯文字。
- **三套主题色 × 浅 / 深 × 多张纸色** —— 雾紫 / 暖黄 / 雾绿，配浅绿 / 雾蓝 / 云灰等耐读纸，自由组合。
- **本地优先 · 注重隐私** —— 数据存在你自己的设备上。
