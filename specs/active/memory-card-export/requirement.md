# memory-card-export（回忆卡片导出屏）

## 背景

「回忆卡片」是把一条 / 一天回忆渲染成**可分享卡片图**的导出向屏（源屏 `ui-design/current/pages/screens/memory.html`）——非日常浏览屏，在方法论 §9 波次里属**依附 / 后置件**（W3/W4），挂在「往年今日」之后由其入口拉起。屏的实质是：在固定顶栏与固定底栏之间预览一张卡片，底栏可切**画幅**（竖版 9:16 / 方形 1:1 / 长图）与**风格**（纸感 / 大图压字），点「保存到相册」或「分享」把当前预览卡片导出为 PNG。

它把一段已存在的回忆数据「翻译」成视觉成品图，因此有两条独立关切：① 还原设计稿的卡片版式与切换交互（UI 还原线，走 token / `ui-kit` / `ui-shell` 既有词汇）；② 把 Flutter widget 离屏栅格化成像素图（`RepaintBoundary` → `toImage()` → PNG → 存相册 / 分享）——后者是本屏区别于其它浏览屏的核心。卡片内容（标题 / 摘要 / 封面 / 地点 / 往年今日多段）经 Repository 取数，**不在本屏碰 Drift / SQL**。

## 范围外

- **真实相册 / 相机选图链路**：本屏不选图；封面图来源是已存在的 entry 媒体（经 `MediaRepo` 元数据 + 缩略图 / 原图 provider）。原生相册链路归 media-picker（独立 spec）。MUST NOT 在本屏触发缩略图同步重建（缩略图红线，见 NF6）。
- **缩略图生成本身**：本屏只**消费**已就绪的 image provider；缩略图 warmup / 生成归 `thumbnail-cache`。本屏 MUST NOT 自行生成缩略图。
- **「往年今日」浏览屏本体**：年份匹配、列表浏览、每日通知归 `onthisday-screen`；本屏只接收其传入的「单条 entry」或「某天聚合」作为导出源。
- **真实分享渠道 / 系统分享面板的目标 App 行为**：本屏调起系统分享（经 `share_plus`），具体分享到哪个 App 由系统决定，不在本屏控制。
- **导出格式扩展**：MVP 只导出 **PNG**；JPG / PDF / 水印自定义 / 多卡批量导出 MUST NOT 在本 spec 引入。
- **卡片视觉模板的扩展**：只实现设计稿登记的两种风格（纸感 / 大图压字）+ 三种画幅；新增模板由 `design-sync-automation` 增量驱动，不在本 spec 预造。
- **token / 通用组件 / 外壳本体**：归 `design-tokens-theme` / `ui-kit-components` / `ui-shell-navigation`；本屏只**引用**它们的交付物（`context.dayz.*`、`DayzButton`/`DayzSegmented`、`Routes`、`DayzToast` 等）。

## 功能需求

> 屏内状态清单（据源屏 `memory.html` 的 `?state=` 与 JS 切换逻辑提炼）：**画幅** = 竖版 `r916`（默认）/ 方形 `r11` / 长图 `long`；**风格** = 纸感 `paper`（默认）/ 大图压字 `photo`；**长图** 固定纸感（切到长图时风格行禁用置灰）。底栏始终可见。导出动作 = 保存 / 分享。

### R1 · 单条回忆卡片预览
系统 SHALL 在预览区渲染一张以单条 entry 为源的回忆卡片，含「往年段标签（如 `2021年5月 · 五年前的今天`）+ 标题 + 摘要 + 页脚（DayZ 字标 + 地点等元信息）」，可选封面图。
- 前提：本屏以一条 entry 作为导出源进入。
- 操作：屏渲染完成。
- 结果：预览区出现单条卡片（`DayzMemoryCard` 等价物），标题 / 摘要 / 往年段 / 页脚字标可见；有封面则显示封面、无封面则按设计稿降级（纸感款照片区缺省占位、大图压字款回落纯色底）。

### R2 · 画幅切换（竖版 / 方形 / 长图）
系统 SHALL 提供画幅分段控件，在「竖版 9:16 / 方形 1:1 / 长图」间切换，预览区即时换为对应画幅的卡片。
- 前提：在本屏。
- 操作：点画幅分段控件的某一项。
- 结果：① 选「竖版」→ 单卡按 9:16 渲染；②「方形」→ 单卡按 1:1 渲染；③「长图」→ 切换为长图卡片（整天多段回忆，可竖向滚动看全貌），单卡隐藏；分段控件选中态随之更新（`aria-selected` 等价的选中语义）。

### R3 · 风格切换（纸感 / 大图压字）+ 长图固定纸感
系统 SHALL 提供风格分段控件，在「纸感 / 大图压字」间切换；When 画幅为「长图」时，风格行 SHALL 置为禁用态（视觉变暗 + 不可点），长图固定纸感版式。
- 前提：在本屏，画幅为竖版或方形。
- 操作：点风格分段控件的某一项 / 切到长图画幅。
- 结果：① 选「纸感」→ 单卡用纸感版式（表面底 + 照片区 + 正文区）；②「大图压字」→ 单卡用大图压字版式（满幅照片 + 底部渐变 + 压白字）；③ 切到「长图」→ 风格行禁用（不可交互），切回竖版 / 方形 → 风格行恢复可交互。

### R4 · 长图：整天多段回忆
系统 SHALL 在「长图」画幅下，以「某天往年今日聚合」为源渲染纵向长卡片：顶部「往年今日 · M月D日」头 + 「这一天，你写过 N 篇」+ 逐段（按年份倒序，每段含年份标 / 可选配图 / 标题 / 正文）+ 页脚（字标 + 「M月D日 · 共 N 段回忆」）。
- 前提：本屏以「某天聚合（≥1 段往年回忆）」作为导出源、画幅切到长图。
- 操作：切到长图画幅。
- 结果：长图卡片可见，段数 == 该日聚合的回忆段数，年份 / 篇数 / 日期文案经 `intl` 格式化（非裸拼接）；长图高度超出预览舞台时，预览舞台内可竖向滚动，底栏保持可见。

### R5 · 保存到相册
系统 SHALL 提供「保存」动作，把当前预览卡片离屏栅格化为 PNG 并写入系统相册，成功后给出 toast 反馈。
- 前提：预览区有一张可导出的卡片。
- 操作：点「保存」。
- 结果：当前卡片（含长图全貌，非仅可视区）被渲染成 PNG 并存入相册；成功 toast（长图 / 单卡文案区分，如「长图已保存到相册」/「已保存到相册」，经 `AppLocalizations`）；If 相册权限被拒或写入失败，then 给出失败 toast、MUST NOT 静默吞错。

### R6 · 分享
系统 SHALL 提供「分享」动作，把当前预览卡片栅格化为 PNG 并调起系统分享面板。
- 前提：预览区有一张可导出的卡片。
- 操作：点「分享」。
- 结果：生成当前卡片 PNG → 调起系统分享（`share_plus`），分享反馈 toast（长图 / 单卡文案区分，经 `AppLocalizations`）；If 分享被取消或生成失败，then 不崩溃、给出可观测反馈或静默回到本屏（取消属正常路径，不报错）。

### R7 · 取数只经 Repository（不持 Drift）
系统 SHALL 仅经 `EntryRepo`（单条 / 往年今日聚合）与 `MediaRepo`（封面媒体元数据）取得卡片内容，MUST NOT 在本屏持有 Drift 句柄或编写 SQL / Drift 查询。
- 前提：本屏需要 entry 内容与封面。
- 操作：取数。
- 结果：所有数据经 Repository 方法（如 `EntryRepo.onThisDay(month, day)` / 单条取 entry）入参传入屏 widget；屏 widget 接收**纯数据模型 + image provider**，可用假数据独立 widget test，源码 import 不含 `package:.../data/`、不含 Drift 句柄。

### R8 · Debug Home 入口
系统 SHALL 在 Debug Home 挂一个本屏 demo 入口（真外壳 / 往年今日入口未全就绪前，这是本屏在真机被看见与走查的入口）。
- 前提：App 进入 Debug Home（或真外壳的 `Routes.debugHome`）。
- 操作：进入 `demos` 列表末尾新增的回忆卡片导出 demo。
- 结果：用假 entry / 假聚合数据渲染本屏，可切画幅 / 风格、可触发保存 / 分享（demo 下可 stub 导出，断言导出被调用即可）。

## 非功能需求

### NF1 · 对比度（按实际渲染对验）
- 纸感款正文 / 标题（`--ink` / `--ink-2` 落 `--surface`）对底 MUST ≥ WCAG AA（4.5:1）。
- 大图压字款压在照片渐变上的白字，其底部渐变遮罩 MUST 足够暗以保证白字对底 ≥ 4.5:1（设计稿底部渐变到 `rgba(20,16,12,0.82)`；按渲染对验，渐变最暗端区域验）。
- 往年段着色文字（`--accent-ink` 落 `--accent-soft`）MUST ≥ 4.5:1。
- 底栏分段控件 / 按钮文字对底 MUST ≥ 4.5:1（按钮文字 `--on-accent` 落 `--accent` 沿用 `ui-kit` 的 `DayzButton` / `DayzSegmented`，对比度由其保证；本屏不重复造按钮）。
> 复用 `design-tokens-theme` 对比度机器真源 `test/ui/theme/contrast_xfail.yaml`；本屏不新建 xfail 源，遇 expected-fail 阻塞放行、报 @Ray。

### NF2 · 点击目标 ≥ 44px
画幅 / 风格分段控件的每个可点项、保存 / 分享按钮、返回钮的可点命中区 MUST ≥ 44×44 逻辑像素。

### NF3 · Semantics 标签
返回钮、画幅 / 风格每项、保存 / 分享按钮 MUST 有无障碍标签（文案经 `AppLocalizations`），可被屏幕阅读器识别；分段控件选中态 MUST 经语义暴露（selected）。

### NF4 · reduce-motion
画幅 / 风格切换、长图滚动、底栏出现等动效 MUST 在系统「减弱动态效果」开启时降级为瞬时（经 `ui-kit` 的 `dayzMotionDuration` 门取时长），不强制动画。

### NF5 · 多端兼容
SHALL 在 iOS 13+ 与 Android 8+ 上正常工作：① 卡片离屏栅格化（`RepaintBoundary.toImage()` 取设备像素比）在两端产出清晰 PNG；② 保存相册 / 分享在两端的权限模型与 API 差异由所选包（`share_plus` + 相册保存包）抹平，失败路径都有反馈（接 R5/R6）。

### NF6 · 媒体红线（缩略图 / 主密码不保护照片）
- 本屏 MUST NOT 在预览或导出路径同步重建缩略图；封面 image provider 由上游（`thumbnail-cache` warmup / `MediaRepo` 原图）提供，本屏只消费（缩略图红线，docs/design/05）。
- 导出生成的 PNG 是**明文像素图**写入系统相册 / 经系统分享外发——这等于把（可能受主密码保护的日记内容里的）文字与照片以明文导出到 App 外。媒体 key 独立于主密码、主密码本就锁不住照片（docs/design/06）；故本屏导出**不受主密码保护**是有意为之，但导出是用户主动且不可逆的外发动作，UI MUST 不暗示「导出物仍受保护」，且导出动作应是显式点击触发（无自动导出）。

### NF7 · 离屏栅格化质量与性能
- 导出 PNG MUST 以 ≥ 设备 `devicePixelRatio`（或固定高倍率，如 3.0）的 `pixelRatio` 栅格化，保证分享图清晰不糊。
- 长图导出 MUST 渲染**完整长卡**（包含滚出可视区的部分），不得只截可视区——通过离屏构建完整尺寸的 `RepaintBoundary` 子树实现。
- 单次导出（含长图）SHOULD 在交互可接受时长内完成；导出进行中 SHOULD 防重复触发（避免连点生成多份）。

## 专项维度逐维表态（选档依据）

| 专项维度 | 命中？ | 依据（一句话） |
|---|---|---|
| 安全 | **是** | NF6：导出 = 明文像素外发，触及「主密码不保护照片」红线，UI 须如实、导出须显式 |
| 权限 | **是** | R5/NF5：写系统相册需相册权限，失败路径须有反馈 |
| 无障碍 | **是** | NF1 对比度 / NF2 命中区 / NF3 Semantics / NF4 reduce-motion |
| 性能 | 否 | NF7 为质量约束（像素比 / 完整长图）非硬性能阈值；不设可度量运行阈值闸 |
| 多端兼容 | **是** | NF5：iOS 13+ / Android 8+ 栅格化 + 相册 / 分享 |

→ 命中「安全 / 权限 / 无障碍 / 多端兼容」（任一即可）→ **标准档**（含 `## 非功能需求` + verification.md + 文件头文档状态 + README 索引）。模块判定见 design `## 文件变更`：全部落 `lib/ui/memory_card_export/` 与 `lib/demo/` + `pubspec.yaml`（单模块 Flutter app `lib/`），不跨模块。
