# DayZ

跨平台、本地优先、注重隐私的日记 App。

## 🌟 核心特性 (Core Features)

- **本地优先 (Local-First)**：数据完全掌握在自己手中。
- **跨平台支持**：基于 Flutter 与 Dart 构建，体验流畅精致。
- **富文本体验**：支持图文混排编辑与无限滚动的优雅时间线。
- **往年今日**：在历史的长河中快速回溯特定的一天。
- **坚如磐石的隐私保护**：采用 SQLCipher 加密本机数据库，并提供基于 Argon2id 的混合密钥机制。
- **无损备份与归档**：支持增量与全量备份，并可导出为精美的 PDF 进行永久归档。

## 🛠 技术栈 (Tech Stack)

- **应用框架**：Flutter / Dart (Stable 渠道最新版)
- **本地数据库**：Drift (SQLite) + SQLCipher 加密
- **媒体存储**：本地文件系统 + 统一缩略图缓存层
